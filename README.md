# The poem about permission

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the [make.fun](https://make.fun) competition
[The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

A program that writes one short poem about agency — the power to ask and
to be given — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The poem is written to `/output/entry.txt` (UTF-8, 249 characters).
